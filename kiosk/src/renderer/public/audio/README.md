# 오디오 에셋

`src/renderer/public/` 아래 파일은 Vite가 그대로 복사한다.
코드에서는 **`./audio/...`** 로 참조한다 (file:// 로딩 때문에 `/audio/...` 절대경로 금지).

## 넣을 파일

| 경로 | 용도 | 규격 |
| --- | --- | --- |
| `audio/speaker-test.mp3` | **D-01 스피커 테스트음** ← 지금 필요 | mp3, 3~5초, 44.1kHz, 스테레오 |
| `audio/bgm/*.mp3` | 대기 화면(P-00)·플로우 배경음 | 미정 |
| `audio/sfx/*.mp3` | 셔터·카운트다운 등 효과음 | 미정 |
| `audio/voice/*.mp3` | 안내 음성 | 미정 |

`speaker-test.mp3` 는 **좌/우 채널이 모두 들리는 소리**면 좋다 — 스피커 한쪽만 물린 상태를 잡아낼 수 있다.

## 파일이 없을 때

`speaker-test.mp3` 가 없으면 D-01은 **코드로 생성한 440Hz 사인파**를 대신 재생한다.
파일을 넣으면 자동으로 파일 쪽이 우선된다.

> ⚠️ Windows 탐색기가 확장자를 숨기고 있으면 `speaker-test.mp3.mp3` 처럼 저장되기 쉽다.
> D-01에서 "파일 없음 → 사인파" 가 뜨면 파일명부터 확인할 것.

## ⚠️ 주의

**녹음 중(P-05·D-01 녹음)에는 모든 오디오 출력을 음소거한다** — BGM·효과음이 마이크에
섞이면 발음 분석이 망가진다 (CLAUDE.md 금지사항 6).
