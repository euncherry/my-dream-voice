> **2026-11-23: 직업별 프레임 6장이 들어 있다** (경찰 보라 · 우주비행사 노랑 · 가수 분홍 · 크리에이터 살구 · 의사 초록 · 로봇개발자 하늘).
> **2026-11-24: 우주비행사 프레임을 새 그림으로 바꿨다** (같은 날 세 번째 판) — 보라 우주 하늘 · 달 표면 · 둥근 모서리 칸 4개(왼쪽 두 칸이 오른쪽보다 좁다). 받은 그림(2000×1349)은 칸이 이미 투명이었다 → 칸 안의 옅은 반투명 얼룩을 지우고(불투명 가장자리 2px 밖의 α<128) · 거의 불투명(α 200~254)은 불투명으로 · 1844×1244로 줄이고 위아래 2px 자름.
> 같은 날 받은 노란 격자 틀(띠 없음)은 가수 시험 프레임 `singer-test.png`로 쓴다 (왼쪽 아래 칸 구름 모양). 두 프레임 모두 칸 자리가 나머지와 달라 **`FOURCUT.cellsByJob`** 에 직업별로 따로 적었다.
> **2026-11-25: 의사 시험 프레임 `doctor-test.png`** — 우주 그림 새 판(보라 하늘 · 달 표면 · 우주비행사 남녀 · 칸 4개 같은 크기). 받은 그림(2000×1318)은 칸이 **검정**이었다 → 왼쪽 투명 여백(47px) 버림 · 1844×1244로 줄이고 위아래 2px 자름 · 검정 칸을 뚫음(캐릭터에 가려 떨어진 검정 조각도 거의 순검정인 것만 — 눈동자 · 그림자는 그대로) · 가장자리 어두운 1px까지. 원래 `doctor.png`는 그대로 있다.

> 어느 직업이 어느 파일을 쓰는지는 `src/renderer/photo/composeFourCut.ts`의 **`FRAME_FILE`** 한 곳에 있다.
>
> 받은 그림은 사진 칸이 흰색이고 오른쪽 아래에 QR이 있다 → 흰 사진 칸 4개를 투명하게 뚫음 · 1844×1240으로 맞춤(우주비행사 1844×1244는 위아래 2px 자름 · 나머지 5장 1527×1030은 1.2배 키우고 위아래 2px 자름) · **QR을 지움**(SPEC "인쇄물에 QR 없음" — 둘레 바둑판으로 덮음). 스티커 그림의 흰 테두리가 칸 테두리선에 겹친 곳(가수 · 크리에이터 · 로봇개발자)은 칸 밖까지 뚫리지 않게, 다른 프레임들의 칸 모양 안에서만 뚫었다.
규격 원본은 `SPEC.md` §4-1 「프레임 작업 규격」 — 아래는 요약이다.

`src/renderer/public/` 아래 파일은 Vite가 그대로 복사한다.
코드에서는 **`./frames/<jobId>.png`** 로 참조한다 (file:// 로딩 때문에 `/frames/...` 절대 경로 금지).

## 파일 이름

`<jobId>.png` — 이름이 다르면 못 찾는다 (`FRAME_FILE`과 맞아야 쓰인다).

| 직업 | 파일 |
| --- | --- |
| 경찰 | `police.png` |
| 우주비행사 | `astronaut.png` |
| 가수 | `singer.png` |
| 크리에이터 | `creator.png` |
| 의사 | `doctor.png` |
| 로봇개발자 | `roboticist.png` |

> ⚠️ Windows 탐색기가 확장자를 숨기고 있으면 `police.png.png` 처럼 저장되기 쉽다.
> 넣었는데도 placeholder 프레임이 나오면 파일 이름부터 확인할 것.

## 규격

| 항목 | 규격 |
| --- | --- |
| 캔버스 | **1844 × 1240 px · 300dpi · 가로 · RGB(sRGB)** — 드라이버 (6x4) 인쇄 페이지와 같아 돌리거나 늘리지 않고 1:1로 인쇄된다 |
| 형식 | PNG (투명 포함) |
| 사진 칸 | **가로 칸 4개 · 모두 같은 크기 · 투명** — 사진을 먼저 그리고 프레임을 그 위(맨 위)에 얹는다. 카메라 원본이 3:2라 칸이 3:2에 가까울수록 덜 잘린다 |
| 오른쪽 세로 띠 | 로고 자리 |
| 실제 종이 | 가운데 1800 × 1200 px (6 × 4 in). 바깥 약 20px(좌우 22 · 위아래 20)은 잘려 나갈 수 있다 → 배경은 끝까지 채우고, **중요한 것은 가장자리에서 60px 안쪽**에 |
| 넣지 않는 것 | **QR 자리 없음** (A · B 같은 프레임) · 추천 직업 없음 |
| 확인 | 염료승화는 모니터보다 진하게 나온다 → 시안으로 실제 테스트 인쇄 (잘림도 이때 잰다 — D-01 테스트 인쇄) |

## 칸 좌표

사진 칸 4개와 오른쪽 띠의 좌표는 **`src/shared/constants.ts` 의 `FOURCUT`** 한 곳에만 있다.
지금 값은 프레임 6장의 투명한 사진 칸을 모두 감싸는 네모(+3px)를 그림에서 잰 것이다 (2026-11-23 — 6장은 칸 자리 · 모양이 같은 틀이고, 칸이 물결 · 구름 모양이라 네 칸 크기가 조금씩 다르다). 프레임이 바뀌면 칸을 다시 잰다 — **칸 자리가 다른 프레임은 `FOURCUT.cellsByJob`에 직업별로** 적는다 (없으면 `FOURCUT.cells`. 지금은 우주비행사 · 가수 시험 · 의사 시험이 따로). `FOURCUT.strip`(오른쪽 띠)은 프레임 그림이 없을 때 그리는 PLACEHOLDER 프레임에서만 쓴다.
그러면 합성(`photo/composeFourCut.ts`) · 화면 미리보기(`photo/FramePreview.tsx`) · 촬영 프리뷰 비율(P-06)이 따라온다.

- 코드는 사진을 `FOURCUT.cells` 의 네모에 꽉 채워 그린다. 프레임의 투명 구멍이 이 네모보다 **크면 흰 틈이 보인다** — 구멍은 칸 좌표와 같거나 조금 작게.
- 칸 순서: 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래 (찍는 순서)
- 크기가 1844 × 1240이 아니어도 캔버스 전체에 맞춰 얹기는 하지만(콘솔에 경고), 비율이 다르면 칸이 어긋난다.

## 파일이 없을 때

파일이 없는 직업은 **코드로 그린 PLACEHOLDER 프레임**이 쓰인다 —
칸 바깥이 직업 색(`src/shared/jobs.ts` 의 `placeholderColor`)이고, 오른쪽 띠에 "마이 드림 보이스" · 직업 이름 · "PLACEHOLDER 프레임" 이 적힌다.
인쇄물에도 그대로 찍히므로 placeholder인지 바로 알 수 있다.

파일을 넣으면 자동으로 파일 쪽이 쓰인다. 있는지는 직업마다 한 번만 확인하므로 **넣은 뒤에는 앱을 다시 띄운다**.
