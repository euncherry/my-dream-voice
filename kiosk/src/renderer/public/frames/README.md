# 직업 프레임 아트

네컷 인쇄물과 화면 미리보기(P-04 직업 카드 · P-06 촬영 옆 패널)에 얹는 **직업 프레임**을 여기에 넣는다.

> **2026-11-23: 지금은 6개 직업이 같은 프레임 하나(`common.png`)를 쓴다** (지정 — "프레임은 두 번째 그림으로 통일").
> 어느 직업이 어느 파일을 쓰는지는 `src/renderer/photo/composeFourCut.ts`의 **`FRAME_FILE`** 한 곳에 있다 — 직업마다 다른 프레임이 오면 아래 이름으로 넣고 `FRAME_FILE`을 바꾼다.
>
> `common.png`는 받은 그림(1844×1244 · 사진 칸이 흰색 · 오른쪽 아래에 QR)을 이렇게 고친 것이다:
> 흰 사진 칸 4개를 투명하게 뚫음 · 위아래 2px씩 잘라 1844×1240 · **QR을 지움**(아래 "넣지 않는 것" — 둘레 바둑판으로 덮음).
규격 원본은 `SPEC.md` §4-1 「프레임 작업 규격」 — 아래는 요약이다.

`src/renderer/public/` 아래 파일은 Vite가 그대로 복사한다.
코드에서는 **`./frames/<jobId>.png`** 로 참조한다 (file:// 로딩 때문에 `/frames/...` 절대 경로 금지).

## 파일 이름 (직업마다 따로 쓸 때)

`<jobId>.png` — 이름이 다르면 못 찾는다 (`FRAME_FILE`도 그 이름으로 바꿔야 쓰인다).

| 직업 | 파일 |
| --- | --- |
| 경찰 | `police.png` |
| 우주비행사 | `astronaut.png` |
| 가수 | `singer.png` |
| 크리에이터 | `creator.png` |
| 의사 | `doctor.png` |
| 로봇개발자 | `roboticist.png` |

> ⚠️ Windows 탐색기가 확장자를 숨기고 있으면 `police.png.png` 처럼 저장되기 쉽다.
> 넣었는데도 placeholder 프레임이 나오면 파일 이름부터 확인할 것.

## 규격

| 항목 | 규격 |
| --- | --- |
| 캔버스 | **1844 × 1240 px · 300dpi · 가로 · RGB(sRGB)** — 드라이버 (6x4) 인쇄 페이지와 같아 돌리거나 늘리지 않고 1:1로 인쇄된다 |
| 형식 | PNG (투명 포함) |
| 사진 칸 | **가로 칸 4개 · 모두 같은 크기 · 투명** — 사진을 먼저 그리고 프레임을 그 위(맨 위)에 얹는다. 카메라 원본이 3:2라 칸이 3:2에 가까울수록 덜 잘린다 |
| 오른쪽 세로 띠 | 로고 자리 |
| 실제 종이 | 가운데 1800 × 1200 px (6 × 4 in). 바깥 약 20px(좌우 22 · 위아래 20)은 잘려 나갈 수 있다 → 배경은 끝까지 채우고, **중요한 것은 가장자리에서 60px 안쪽**에 |
| 넣지 않는 것 | **QR 자리 없음** (A · B 같은 프레임) · 추천 직업 없음 |
| 확인 | 염료승화는 모니터보다 진하게 나온다 → 시안으로 실제 테스트 인쇄 (잘림도 이때 잰다 — D-01 테스트 인쇄) |

## 칸 좌표

사진 칸 4개와 오른쪽 띠의 좌표는 **`src/shared/constants.ts` 의 `FOURCUT`** 한 곳에만 있다.
지금 값은 `common.png`의 투명한 사진 칸 4개를 감싸는 네모(+3px)를 그림에서 잰 것이다 (2026-11-23 — 칸이 물결 · 구름 모양이라 네 칸 크기가 조금씩 다르다). 프레임이 바뀌면 `FOURCUT.cells`를 다시 잰다. `FOURCUT.strip`(오른쪽 띠)은 프레임 그림이 없을 때 그리는 PLACEHOLDER 프레임에서만 쓴다.
그러면 합성(`photo/composeFourCut.ts`) · 화면 미리보기(`photo/FramePreview.tsx`) · 촬영 프리뷰 비율(P-06)이 따라온다.

- 코드는 사진을 `FOURCUT.cells` 의 네모에 꽉 채워 그린다. 프레임의 투명 구멍이 이 네모보다 **크면 흰 틈이 보인다** — 구멍은 칸 좌표와 같거나 조금 작게.
- 칸 순서: 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래 (찍는 순서)
- 크기가 1844 × 1240이 아니어도 캔버스 전체에 맞춰 얹기는 하지만(콘솔에 경고), 비율이 다르면 칸이 어긋난다.

## 파일이 없을 때

파일이 없는 직업은 **코드로 그린 PLACEHOLDER 프레임**이 쓰인다 —
칸 바깥이 직업 색(`src/shared/jobs.ts` 의 `placeholderColor`)이고, 오른쪽 띠에 "마이 드림 보이스" · 직업 이름 · "PLACEHOLDER 프레임" 이 적힌다.
인쇄물에도 그대로 찍히므로 placeholder인지 바로 알 수 있다.

파일을 넣으면 자동으로 파일 쪽이 쓰인다. 있는지는 직업마다 한 번만 확인하므로 **넣은 뒤에는 앱을 다시 띄운다**.
