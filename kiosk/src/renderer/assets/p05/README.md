# P-05 [발화] 장면 그림 · 캐릭터 목소리

여기에 파일을 넣으면 앱을 다시 띄울(빌드할) 때 저절로 쓰인다 — 코드는 고칠 것이 없다 (`p05/media.ts`).
없는 파일은 화면에 **임시 판**(장면 번호 + 장면 설명)과 **자막만**으로 대신한다.

대본 · 장면 설명: `docs/P05_SCENARIO.md` · 코드 쪽 대본: `src/renderer/p05/script.ts`

## 장면 그림 — `scenes/<직업>/<장면 번호>.webp`

| 직업 폴더 | 장면 번호 |
| --- | --- |
| `police` | `P-01` ~ `P-14` · `P-10b` |
| `astronaut` | `A-01` ~ `A-14` · `A-13b` |
| `singer` | `S-01` ~ `S-14` |
| `creator` | `C-01` ~ `C-14` |
| `doctor` | `D-01` ~ `D-14` · `D-13b` |
| `roboticist` | `R-01` ~ `R-14` · `R-10b` · `R-13b` |

예) `scenes/astronaut/A-03.webp` — webp · png · jpg 아무거나

**두 가지 그림을 다 받는다** (앱이 그림을 재서 알아서 맞춘다)

1. **튀어나오는 그림** (2026-11-23 A-01부터 — 추천) — **바탕이 투명**하고, 그 위에 **둥근 판**(장면)이 있고, 캐릭터 머리 · 로켓 끝 같은 것이 **판 위로 튀어나온** 그림.
   앱이 판을 그림 칸에 맞추고, 튀어나온 부분은 칸 위(흰 카드 안)로 보이게 한다 (시안의 로켓 끝처럼).
   - 그림 칸의 높이가 바뀐다 (2026-11-23): 안내 대사 동안은 카드에 꽉 차서 **2.6 : 1**(1338 × 512), 따라 말할 말(큰 글씨)이 나오는 동안은 **3.1 : 1**(1338 × 430)로 줄어든다
   - 판 비율은 **2.6 ~ 2.65 : 1**이 좋다 (A-01이 2.65 : 1 — 안내 대사 동안 다 보인다). 따라 말할 말이 나오는 장면(아이 차례 -06 · 문장 시범 -10 · -13 · 연습 반응 등)에서는 **아래가 조금 잘린다** — 얼굴 · 중요한 것은 위쪽 3/4 안에
   - 튀어나오는 높이는 판 폭의 9% 안쪽 (1890 폭이면 약 170px — 화면에서 칸 위 120px) — 그 위는 잘린다
   - 판의 양옆 끝 8% 안쪽에는 튀어나오는 것을 두지 않는다 (앱이 그 자리로 판의 높이를 잰다)
2. **꽉 찬 그림** — 바탕까지 다 칠한 네모 그림. 칸을 꽉 채우고 비율이 다르면 위아래가 조금 잘린다

- 화면의 그림 칸은 **가로로 긴 3.1 : 1** (앱 화면에서 1338 × 430). 받는 그림은 **1920 × 620** 안팎이 좋다
- 칸을 꽉 채우고, 비율이 다르면 **위아래가 조금 잘린다** (가운데보다 살짝 위를 기준으로) — 캐릭터 얼굴 · 중요한 물건은 가운데 쪽에
- **아래쪽 가운데는 자막 알약이 덮는다** (그림 높이의 아래 약 20%) — 거기에 중요한 것을 두지 않는다

## 캐릭터 목소리 — `voice/<직업>/<대사 이름>.mp3`

예) `voice/astronaut/mission.mp3` — mp3 · wav · m4a 아무거나. 대사 글자는 `p05/script.ts`(직업마다 다른 대사)와 `COMMON`(모든 직업 같은 대사).

| 대사 이름 | 누가 | 대사 |
| --- | --- | --- |
| `hello` | 이끔 | 인사 ("안녕! 나는 ○○야!") |
| `role` | 짝꿍 | 역할 주기 ("오늘 너는 우리 ○○야!") |
| `mission` | 이끔 | 임무 |
| `signal` | 이끔 | "마이크가 반짝이고, 띵! 소리가 나면 그때 말하는 거야." — 띵은 앱이 따로 낸다 (목소리 파일에 넣지 않는다) |
| `demo` | 짝꿍 | "내가 먼저 해 볼게! 준비 완료!" |
| `practice` | 이끔 | "이번엔 네 차례야! 준비 완료!" |
| `loud` · `quiet` | 짝꿍 | 연습 반응 — 크게 / 작게 ("너~무 멀리 있나 봐") |
| `silent` | 이끔 | 연습 반응 — 무음 ("아직 못 들었나 봐! 한 번만 더, 준비 완료!") |
| `intro1` · `intro2` | 이끔 | "첫 번째 신호! 잘 듣고 똑같이 말해 줘." · "두 번째 신호! …" (만 5 · 6세) |
| `intro1-4` · `intro2-4` | 이끔 | "첫 번째 신호! 하나씩 따라 해 줘." · "두 번째 신호! …" (만 4세) |
| `line1` · `line2` | 이끔 | 따라 말할 문장 ① ② — 만 4 · 5세 문장 |
| `line1-6` · `line2-6` | 이끔 | 따라 말할 문장 ① ② — 만 6세 이상 문장 |
| `line1-w1` · `line1-w2` … | 이끔 | 만 4세 어절마다 (문장 ①의 1번째 · 2번째 어절 …) |
| `retry` | 짝꿍 | "멋진 목소리! ○○가 한 번 더 듣고 싶대." |
| `retry-lead` | 이끔 | "다시 한 번, 잘 듣고 똑같이!" |
| `cheer1` · `cheer2` · `cheer3` | 짝꿍 | "좋아!" · "멋져!" · "최고야!" |
| `bridge` | 짝꿍 | 이어 주기 (문장 ①과 ② 사이) |
| `outro` | 둘이 같이 | 마무리 ("이제 사진을 찍으러 가자!") |

- 목소리 파일이 있으면 그 길이만큼 자막을 보여 주고, 없으면 글자 수만큼(한 글자 0.15초 · 최소 1.5초)
- ⚠️ 녹음 중에는 어떤 소리도 내지 않는다 (CLAUDE.md 금지사항 6) — 목소리 · 띵은 늘 녹음 전에 끝난다
