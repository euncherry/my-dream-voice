마이 드림 보이스 화면 흐름도

어느 화면에서 무엇을 하면 어느 화면으로 가는지 정리한 문서입니다. 키오스크 앱을 1920×1080 화면으로 직접 돌려 캡처했습니다. 개발 중인 지금 상태 그대로라서, 임시 표시와 개발용 버튼도 함께 보입니다.

이런 문서를 부르는 이름
유저 플로우(User Flow), 한국어로 화면 흐름도입니다. 실제 화면을 붙인 형태는 와이어플로우(Wireflow)라고 합니다.
두 가지 체험 경로
A모드는 네컷 사진만 찍습니다. B모드는 목소리 분석과 보호자 리포트까지 받습니다.

캡처 조건

  • 실제 프린터로는 아무것도 보내지 않았습니다. 인쇄 실패 화면은 없는 프린터 이름을 골라 만들었습니다.
