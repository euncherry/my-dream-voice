고른 직업의 짧은 시나리오가 장면 그림으로 흘러갑니다. 직업마다 그 직업 유니폼을 입은 남자아이 · 여자아이 둘이 이끌고, 그림 안 말풍선이 지금 말하는 아이를 가리킵니다 (여자아이 분홍 · 남자아이 파랑 · 둘이 같이 보라). 배경이 같으면 인물 포즈만 스르르 바뀌고, 배경이 바뀌면 장면째 옆으로 넘어갑니다. 아이 차례는 "준비 완료!" 연습 한 번 + 문장 두 번입니다.
