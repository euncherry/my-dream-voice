## 0. 정한 것 (2026-11-23)

| 항목 | 정한 내용 |
| --- | --- |
| 목적 | 한글을 못 읽는 4 ~ 6세 아이가 **캐릭터를 따라 말하게** 이끈다. "따라 해"라는 지시보다 **역할 + 임무**로 말할 이유를 준다 |
| 캐릭터 | 직업마다 **남자아이 · 여자아이 둘 다** 나오고, **그 직업 유니폼**을 입는다 (경찰이면 둘 다 경찰복, 우주비행사면 둘 다 우주복). 타이틀 · 공용 화면의 캐릭터는 지금 그대로 |
| 역할 나누기 | **이끄는 캐릭터** = 따라 말할 문장을 먼저 들려준다 (한 시나리오 안에서는 문장을 늘 이 캐릭터가 말한다 — 누구를 따라 할지 헷갈리지 않게)<br>**짝꿍 캐릭터** = 아이 편. 연습 때 먼저 시범을 보이고, 아이가 말하면 응원한다<br>이끄는 캐릭터는 직업마다 번갈아 — 남자아이 3개 · 여자아이 3개 (아래 표) |
| 말하는 신호 | **버튼 없음.** 캐릭터가 말을 마치면 **마이크가 반짝이고 '띵!'** 소리가 난다 → 띵이 끝나고 0.3초 뒤 녹음 시작<br>'띵!'은 이 신호에만 쓴다 (다른 소리와 겹치면 헷갈린다). 띵 소리는 녹음에 섞이지 않게 녹음 **전에** 끝난다 (녹음 중 소리 금지 — CLAUDE.md 금지사항 6) |
| 녹음 끝 | 말을 시작한 뒤 **약 1초 조용하면** 저절로 끝난다. 아예 말이 없으면 **최대 시간**에 끝난다 (만 4세 어절 약 4초 · 문장 약 6초 — 임시, SPEC T-19) |
| 연습 한 번 | 진짜 문장 전에 **"준비 완료!"** 를 한 번 해 본다 — 차례 주고받기를 익히고, 쑥스러움을 푼다. **분석하지 않는다**<br>판단은 **목소리 크기로만** 한다 (받아쓰기 안 씀 — 짧은 말은 받아쓰기가 자주 틀리고, 아이 화면에서 발음을 평가하지 않기 위해) |
| 연습 반응 | **크게 말함** → 칭찬 · 바로 진행<br>**작게 말함** → "멀리 있어서 크게 불러야 해" (탓은 이야기 속 대상에게) · 연습은 다시 안 하고 진행<br>**아무 말 없음** → 한 번만 다시 연습 → 그래도 없으면 그냥 진행 |
| 따라 말할 문장 | 직업마다 **2개**. **만 4 · 5세는 같은 문장** (만 4세는 어절마다 끊어 하나씩) · **만 6세 이상은 따로** (조금 긴 문장)<br>목표 소리: 만 4 · 5세 **ㅅ · ㄹ** · 만 6세 이상 **ㅅ · ㅆ · ㄹ** (SPEC §3-2) |
| 다시 말하기 | 받아쓰기 인식률 50% 미만이면 1회 (지금 정의 그대로). 버튼이 없으므로 **캐릭터 멘트 → 문장을 한 번 더 들려줌 → 띵 → 녹음** 으로 자동 진행 |
| 말투 원칙 | 칭찬은 **해 준 것**에만 ("고마워!", "신호가 갔어!"). "발음이 좋다 · 정확해 · 틀렸어 · 다시 · 안 들려 · 잘 못했어"는 쓰지 않는다 (CLAUDE.md 금지사항 7 · 8)<br>"잘했어, 하지만 ~" 대신 **잘한 것 + 다음 임무**로 말한다<br>질문으로 끝내지 않는다 ("같이 해 볼까?" → 아이가 "응!" 하고 답한다). 끝은 **"똑같이 말해 줘!"** 처럼 분명하게 |

- **A ~ D(안내 부분)가 약 15초.** 나이와 상관없이 직업마다 하나다 → 만들 것은 6개
- 전체는 만 5 · 6세 약 55 ~ 60초, 만 4세는 어절마다 주고받아 약 80초
- **만 4세**: F에서 "하나씩 따라 해 줘!" → 어절마다 [시범 → 띵 → 녹음]을 반복한다 (예: "로켓" → 띵 → 아이 "로켓" → "발사!" → 띵 → …)
- **"잘 듣고 있어요"**: 받아쓰기를 기다리는 동안 **짝꿍이 귀 기울이는 자세** + 자막 "잘 듣고 있어요" (따로 고민하는 표정 그림을 두지 않고 짝꿍 그림을 쓴다 — 그림 수를 줄이려고)

## 3. 필요한 그림 · 목소리

### 그림 (직업마다)

| 무엇 | 장수 | 비고 |
| --- | --- | --- |
| 배경 | 2장 | 시작 장소 (A ~ F1) · 이어 주기 장면 (G ~ I) — 위 표의 **굵은 글씨** 장면 |
| 남자아이 (직업 유니폼) | 3장 | **말하기 · 귀 기울이기 · 환호** — 투명 배경 |
| 여자아이 (직업 유니폼) | 3장 | 같음 |
| (선택) 말하기 입 다문 그림 | 남녀 각 1장 | 말하는 동안 입 벌림 / 다뭄을 번갈아 보여 주면 "말하는 느낌"이 난다 |
| 소품 | 필요하면 | 경찰 무전기 · 로켓 · 마이크 · 카메라 · 곰돌이 · 로봇 — 배경에 그려도 된다 |

→ 6개 직업 합계: 배경 12장 · 캐릭터 36장 (+ 입 다문 그림 12장). 우주비행사의 **남자아이 우주복** 그림이 새로 필요하다 (타이틀 화면의 경찰 남자아이는 그대로).

### 공통

| 무엇 | 비고 |
| --- | --- |
| '띵!' 효과음 1개 | 짧고 맑게 (0.3초 안팎). 이 신호에만 쓴다 |
| 마이크 반짝 · 소리 크기 막대 | 앱이 코드로 그린다 |

### 목소리

- **남자아이 · 여자아이 두 명.** 위 대사를 직업마다 녹음한다
- **따라 말할 문장**은 이끄는 캐릭터 목소리로 — 또렷하게, 보통보다 조금 천천히, 과장하지 않은 억양으로 (아이가 억양까지 따라 한다)
  - 만 4 · 5세 문장 2개 + **만 4세용 어절 하나씩**(따로 천천히 녹음) + 만 6세 이상 문장 2개
- 직업마다 대략 이끔 12개 · 짝꿍 8개 안팎의 파일

## 4. 확인이 필요한 것

1. **따라 말할 문장 24개** (직업 6 × 만 4·5세 2 + 만 6세 이상 2) · 만 4세 끊는 위치 — 전문가 확인 (SPEC T-3)
2. 만 4 · 5세를 **같은 문장**으로 둘지 (지금 초안) — SPEC §3-2도 두 나이를 같은 목표 소리로 두고 있다
3. 녹음 끝 기준 (조용함 약 1초 · 최대 시간 약 4초 / 6초) — 실제 아이 녹음으로 맞춘다 (T-19)
4. 연습 반응의 "크게 / 작게" 기준 소리 크기 — 키오스크 마이크로 재어 정한다
