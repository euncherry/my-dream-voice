## 1. 리포트 공통 구조

두 시나리오의 뼈대는 동일하며, **「다르게 인식됨」이 있을 때만** ‘가능한 이유 안내’와 ‘집에서 들어보기’ 섹션이 추가된다.
결과에 관계없이 톤은 **평가서가 아닌 체험 기념품 수준**으로 일정하게 유지한다.

| 순서 | 섹션 | 내용 |
| --- | --- | --- |
| 1 | 헤더 | 아이 이름, 연령, 날짜, 장소 |
| 2 | 오늘 참여한 직업 | 선택한 4종 (기록) |
| 3 | 오늘 말한 문장 | 직업별 대사 4개 (기록) |
| 4 | 오늘 살펴본 소리 | ㅅ · ㅆ · ㄹ (연령별 상이) |
| 5 | 왜 이 소리들을 살펴봤나요? | 연령대별 안내 문구 |
| 6 | 오늘의 관찰 결과 | 음소별 「잘 인식됨 / 다르게 인식됨」 |
| 7 | (조건부) 가능한 이유 + 집에서 들어볼 연습 문장 | 다르게 인식된 경우에만 |
| 8 | 격려 마무리 | 항상 긍정 |
| 9 | 면책 문구 | 의료적 진단 아님 명시 |

## 2. 연령대별 「왜 살펴봤나요」 문구

| 연령대 | 문구 |
| --- | --- |
| 만 4-5세 | "ㅅ, ㄹ 같은 소리는 대체로 이 시기 아이들이 한창 익혀가는 소리예요. 그래서 오늘 직업 문장에 담아 어떻게 들리는지 살펴봤어요." |
| 만 6-7세 | "ㅅ, ㅆ, ㄹ 소리는 우리말에서 비교적 늦게까지 익혀지는 소리로 알려져 있어요. 이 시기 아이들이 자연스럽게 익혀가는 소리라, 오늘 직업 문장에 담아 어떻게 들리는지 살펴봤어요." |
| 만 8세+ | "ㅅ, ㅆ, ㄹ 소리는 우리말에서 또렷하게 내기 까다로운 편이에요." (발달 맥락 설명 없음) |

## 3. 시나리오 ① — 잘 인식된 경우 (만 6세)

```
마이 드림 보이스 · 오늘의 발화 관찰 리포트
OO어린이 (만 6세) · 2026.○.○ · 한국잡월드

오늘 참여한 직업     경찰관 · 소방관 · 요리사 · 가수

오늘 말한 문장
  경찰관 — "시민 여러분을 지키겠습니다! 충성!"
  소방관 — "불을 끄러 출동합니다!"
  요리사 — "맛있게 만들어요!"
  가수   — "사랑을 노래할게요!"

오늘 살펴본 소리     ㅅ · ㅆ · ㄹ

왜 이 소리들을 살펴봤나요?
  ㅅ, ㅆ, ㄹ 소리는 우리말에서 비교적 늦게까지 익혀지는 소리로 알려져 있어요.
  이 시기 아이들이 자연스럽게 익혀가는 소리라, 오늘 직업 문장에 담아
  어떻게 들리는지 살펴봤어요.

오늘의 관찰 결과
  • 'ㅅ' 소리 — 여러 문장에서 또렷하게 잘 인식되었어요!
  • 'ㅆ' 소리 — 또렷하게 잘 인식되었어요!
  • 'ㄹ' 소리 — 또렷하게 잘 인식되었어요!

  오늘은 살펴본 소리들이 목표 소리와 잘 맞게 인식되었어요.

오늘 OO이는 네 가지 직업을 씩씩하게 체험했어요. 멋진 하루였어요! 🌟

이 결과는 오늘 말한 네 문장에서 관찰된 내용이며, 발달을 평가하는 것이 아니라
참고용 안내예요. AI가 인식한 결과를 알려드리는 것으로, 의료적 진단이 아닙니다.
```

## 4. 시나리오 ② — 다르게 인식된 경우 (만 5세)

```
마이 드림 보이스 · 오늘의 발화 관찰 리포트
OO어린이 (만 5세) · 2026.○.○ · 한국잡월드

오늘 참여한 직업     경찰관 · 소방관 · 요리사 · 가수

오늘 말한 문장
  경찰관 — "출동! 사건 현장으로!"          ← 만 4-5세용 짧은 문장
  소방관 — "불을 끄러 출동합니다!"
  요리사 — "맛있게 만들어요!"
  가수   — "사랑을 노래할게요!"

  ㅅ, ㄹ 같은 소리는 대체로 이 시기 아이들이 한창 익혀가는 소리예요.
  그래서 오늘 직업 문장에 담아 어떻게 들리는지 살펴봤어요.

오늘의 관찰 결과
  • 'ㅅ' 소리 — 일부 문장에서 다르게 인식되었어요
  • 'ㄹ' 소리 — 또렷하게 잘 인식되었어요!

(다르게 인식된 경우에만 노출)
가능한 이유 안내
  — 주변 소음이나 마이크와의 거리, 긴장 등 외부 요인의 영향일 수 있어요.

집에서 들어보기
  — (연습 문장 제시)

오늘 OO이는 네 가지 직업을 씩씩하게 체험했어요. 멋진 하루였어요! 🌟

이 결과는 오늘 말한 네 문장에서 관찰된 내용이며, 발달을 평가하는 것이 아니라
참고용 안내예요. AI가 인식한 결과를 알려드리는 것으로, 의료적 진단이 아닙니다.
```

> ⚠️ 시나리오 ②의 「가능한 이유 안내」·「집에서 들어보기」 세부 문구는 원문 PDF에서 잘려 있어 **확정 문구 확보 필요** (SPEC T-3 관련). 스파이크에서는 위 임시 문구로 레이아웃만 검증한다.

## 5. 마크업 시 주의

- **폰트 파일을 로컬에 포함**할 것 (오프라인 환경 — 웹폰트 CDN 금지)
- 템플릿은 **1개**, 데이터만 주입 (웹 페이지 · PDF 공용)
- 이모지(🌟)는 폰트에 따라 렌더가 다를 수 있으므로 PDF 출력 확인 필요
- 조건부 섹션(7번)은 `hasDifferent === true`일 때만 렌더
- 아동의 실제 인식 결과(예: "사건 → 다건")는 **표기하지 않는다** — 음소 단위 결과만
